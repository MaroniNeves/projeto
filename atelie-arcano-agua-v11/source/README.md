# Ateliê Arcano — Água viva 3D

Chuva tridimensional, poças crescendo, lagoa se formando e temporal animado, usando malhas, shaders GLSL e ondas Three.js. Implementação original para jogo. Sem copiar pacotes Godot/GPL nem usar sprites como magia 3D.

Referências pesquisadas:
- MIT: https://github.com/boona13/threejs-grass-water-shaders
- GPL-3.0, apenas referência, não reutilizado: https://github.com/BitOpenCode/rain-puddle

Executar: npm install && npm run build. Use servidor HTTP para abrir dist.

Manter páginas separadas para V8, Rollshade, Lightning e Água, sem misturar renderizadores.
